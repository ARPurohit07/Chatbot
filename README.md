# College Admission Chatbot 

This is a Python-based chatbot that helps students with college admission-related queries like courses, fees, deadlines, etc. It uses NLP and machine learning to classify user intent.

## Features
- Trained on custom `intents.json`
- Learns using Scikit-learn & NLTK
- Supports small talk like "Who made you?"
- Easy retraining via `train_model.ipynb`

## How to Run
```bash
python chatbot.py
